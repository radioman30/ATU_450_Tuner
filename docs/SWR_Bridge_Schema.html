FORMULE SWR
COEFICIENT REFLEXIE
Γ = V_REV / V_FWD

SWR
SWR = (1 + Γ) / (1 − Γ)

PUTERE REFLECTATA %
ρ = Γ² × 100%

IN COD (Arduino)
gamma = revRaw / fwdRaw
swr = (1+gamma)/(1-gamma)
